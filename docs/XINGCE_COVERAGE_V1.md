# Lumi 全行测题型覆盖契约 v1

## 当前结论

Lumi 的产品目标现为覆盖所有规范行测题型，而不是“题库 + 泛聊天”。截至
2026-07-14，31 个子型都已有各自的可验证学习闭环和不可变内容版本，并全部完成
产品发布。条件逻辑沿用既有受控发布；另外 30 个题包由两位不同真人完成内容审核。
负责人于 2026-07-14 明确免除“逐型 human-local 浏览器验收”作为发布阻断，因此
矩阵 31 行均为 `released`。

该决定只说明题型内容与机制可用。每行均机器可读地记录
`acceptance_basis: owner_acceptance_waiver`、日期、被免除的门禁，以及
`human_effect_evidence: unavailable`。它不伪造真人轨迹，也不支持可用性、学习效果、
群体错因率、因果或公平性结论。

本文件和 [`coverage-matrix.v1.json`](../domains/content/xingce/coverage-matrix.v1.json)
是该结论的唯一可执行边界。矩阵不含任何题干、选项或答案，故可安全提交；真实
题目只能经题库工厂版本化导出，或以有权利记录的原创题包发布。

## “一个题型发布”的严格定义

每个矩阵行都必须同时满足：

1. 有来源/权属、内容哈希和人工审核绑定的不可变题包；
2. 有该题型专用的确定性评分、至少两个**未确认**候选错因和能区分它们的最小探查；
3. 有针对探查结果的微课或渐进帮助，以及从未展示、无提示的平行迁移题；
4. 仅由独立迁移证据驱动可解释的 KT/复习提交；首答、探查和受帮助练习只能作为观察；
5. 有隔离 evaluation 和确定性契约测试；
6. 在本地 runtime 中注册并能展示题目、材料或图形、证据、状态变化和回放；
7. 发布记录绑定负责人决定。若逐型真人验收被免除，必须显式写明 waiver、日期、被免除门禁、
   `human_effect_evidence: unavailable` 和仅限“内容与机制可用”的声明边界。

代表性 fixture、源题数量、模型生成文本、一次答对或 synthetic 学习者都不能替代
上述要求。常识和政治题还必须带权威来源快照及有效截止日；图形、图表和资料题必须绑定
不可变资产/材料摘要和可访问替代文本或表格。

逐型真人浏览器闭环现在是**发布后证据目标**，不再是发布门禁。没有该证据时，可以称
“题型已发布”，但不能称“已完成人体验收”或“已证明学习有效”。

子型是对 `xingcetiku` 可见的规范模块、子类和历史试卷结构的产品归并：言语含逻辑
填空、片段阅读、语句填空/排序；数量含数字推理和数学运算；判断含图形、定义、类比、

来源数据中可见的知识域分开。未能规范归并的源行必须进入 `unclassified` 队列，而不能
被静默计入已覆盖类型。

## 题库事实与边界

`xingcetiku` 的源 bundle manifest 声明 78,179 题、77,704 题 ready；Lumi 的
`cleaned17-v2` 导出在首答可见面安全扫描后另将 9 题隔离，产品实际开放 77,695 题，
其余 484 题保持 `needs_review`。原始
`module/sub_category` 字段存在大量空值和试卷段落文本。当前只读统计中有 38,515 行
模块/子类均为空，另有 1,726 条资料分析与 1,447 条言语行缺少细分子类。它说明需要
版本化映射与逐题审核，不说明这些行已经适合学习产品。

现有 100 题 sidecar 富化已验证 10 个候选技能和 31 个候选错因映射的机制，但其状态
仍是 `candidate`：它不能变成个体诊断或 release-ready 内容。外部/回忆版原题也不能
被复制到 Lumi Git；仅能由数据工厂生成本地受控导出，并在导出 manifest 中保留来源、
摘要、质量状态和权属结论。

## 实施顺序

1. **共享契约与路由**：已完成。矩阵、类型专用错因和独立迁移政策可由
   `test_xingce_all_type_coverage.py` 验证。
2. **题包与内容审核**：已完成。每个非条件逻辑子型都有自己的题干、评分、候选错因、探查、
   微课、无提示迁移和延迟复习；30 个审核版都绑定同一份完成的逐题审核工作簿哈希。
3. **产品发布**：已完成。31 行均绑定 2026-07-14 的负责人 waiver 决定；30 个通用题包的
   manifest 另存独立 `product_release`，不重写两位内容审核人的原签名。
4. **真人产品证据**：未完成且不再阻断发布。后续自愿 human-local 走查只能新增真实证据；
   不得自动作答、补写轨迹或据此宣称学习效果。

这份顺序优先建立可复用但不掩盖题型差异的底座；它不授权将未审核题库、群体错误率或
synthetic 轨迹投射进真人学习状态。

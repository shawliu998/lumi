## 题目逐项审阅

### D01 · 入口诊断：只有，从结果回推必要条件

**题干**：在本题设定中，园区严格执行规则（不考虑违规领取、记录错误或系统故障）：只有完成门禁登记，才能领取工作牌。小周已经领取工作牌。以下哪项一定为真？

| 选项 | 内容 | 意图 |
| --- | --- | --- |
| A | 小周已经完成门禁登记。 | **正确** |
| B | 任何完成门禁登记的人都已经领取工作牌。 | 逆命题 |
| C | 小周领取工作牌是因为他认识园区工作人员。 | 无依据前提 |
| D | 小周无需完成门禁登记也能领取工作牌。 | 与规则矛盾 |

- 形式化：`领取工作牌 → 完成登记；领取工作牌；因此完成登记`
- 格式：`conclusion_selection`；技能：条件句方向、必要/充分角色；候选：M-DIR、M-ROLE、M-READ
- 记录哈希：`a9f6d4c4a543bc2831ab0867b3b9ab8eb0c4c6a9486afb86c6cceffe41f9f830`

### D02 · 路由诊断：只要，用逆否方向推理

**题干**：在本题设定的逻辑系统中，规则为：若设备完成校验，指示灯必亮（不考虑故障等其他因素）。现知某设备的指示灯没有亮。以下哪项可以必然推出？

| 选项 | 内容 | 意图 |
| --- | --- | --- |
| A | 该设备完成校验后也不一定会亮。 | 与规则矛盾 |
| B | 该设备没有完成校验。 | **正确** |
| C | 该设备之前一定亮过。 | 无依据前提 |
| D | 该设备不需要校验。 | 无关结论 |

- 形式化：`完成校验 → 亮灯；非亮灯；因此非完成校验`
- 格式：`conclusion_selection`；技能：条件推理有效性；候选：M-INF、M-READ
- 记录哈希：`374ed0c422f72106753452e911eddfdf6abe4ab0f95cf91c3121f2dd7c47ec99`

### P01 · 最小探查：只有的箭头方向

**题干**：“只有通过身份核验，才能进入资料室”应写成哪一种关系？

| 选项 | 内容 | 作者映射 |
| --- | --- | --- |
| A | 通过身份核验 → 进入资料室 | M-DIR：support；M-READ：insufficient |
| B | 进入资料室与身份核验没有关系 | 两者：insufficient |
| C | 进入资料室 → 通过身份核验 | **正确**；两者：refute |
| D | 进入资料室 ↔ 通过身份核验 | 两者：insufficient；双条件只作为干扰项 |

- 形式化：`进入资料室 → 通过身份核验`；格式：`relation_encoding`
- **关键约束**：上述 support/refute/insufficient 都是未确认候选的证据更新，绝不确认学习者“有某错因”。
- 记录哈希：`61ddc8a86db983df1f759e75eab903b151f58a2183d2cebbcf6ac6900723fbca`

### P02 · 最小探查：必要不等于充分

**题干**：规则是“领取设备 → 已登记”。下列哪种情况与该规则相容，并能反驳“已登记 → 领取设备”？

| 选项 | 内容 | 作者映射 |
| --- | --- | --- |
| A | 某人已登记，并且已经领取设备。 | M-ROLE：support；M-READ：insufficient |
| B | 某人未登记，也没有领取设备。 | 两者：insufficient |
| C | 某人领取了设备，却没有登记。 | 两者：insufficient（违反原规则） |
| D | 某人已登记，但还没有领取设备。 | **正确**；两者：refute |

- 形式化：`领取 → 登记；登记 ∧ 非领取` 是 `登记 → 领取` 的兼容反例；格式：`countermodel_selection`
- 记录哈希：`f4192b0802f0e528566d0523b7e7dfe157948c77b1b7abd6aaea5daa79a98230`

### P03 · 最小探查：脱离语境的条件推理

**题干**：已知 P→Q，且 Q 为真。下列哪项能必然推出？

| 选项 | 内容 | 作者映射 |
| --- | --- | --- |
| A | P 为假。 | 两者：insufficient |
| B | 无法仅凭这些信息确定 P 的真假。 | **正确**；两者：refute |
| C | P 为真。 | M-INF：support；M-READ：insufficient |
| D | Q 为假。 | 两者：insufficient |

- 形式化：`P → Q；Q；P` 未定；格式：`entailment_selection`
- 记录哈希：`5c1001d040b1af51ebf1abc02f8566223ffc2213919cba5a410810a072765cf0`

| 选项 | 内容 | 意图 |

| A | 已取得安全授权，操作台未启用。 | 相容：必要不代表行为已发生 |
| B | 已取得安全授权，操作台已启用。 | 相容 |
| C | 未取得安全授权，操作台未启用。 | 相容 |

| 选项 | 内容 | 意图 |
| --- | --- | --- |
| A | 推理无效，因为它否定了条件句的前件。 | 错误分类 |
| B | 推理有效，因为它使用了“终审通过 → 材料齐备”的逆否形式。 | **正确** |
| C | 推理无效，因为材料齐备只是终审通过的必要条件。 | 误读必要条件与逆否 |
| D | 推理有效，因为材料齐备能够推出终审通过。 | 用逆命题给出错误理由 |

- 格式：`argument_evaluation`，不同于 D02 的结论选择；`requires_no_hints=true`
- 新情境、独立组：`transfer-inference-01`

## 技能与候选错因

| ID | 技能 / 候选错因 | 审阅关注点 |
| --- | --- | --- |
| S1 | 条件句的自然语言方向 | 是否把“只有 A，才 B”稳定地写为 B→A |
| S2 | 必要条件与充分条件角色 | 是否能用兼容反例说明“必要不等于充分” |
| S3 | 条件推理有效方向 | 是否拒绝肯定后件、否定前件等无效推理 |
| M-DIR | 把“只有”读成反向条件 | 只可作为未确认候选；由 P01 进行最小探查 |
| M-ROLE | 把必要条件当作充分条件 | 只可作为未确认候选；由 P02 进行最小探查 |
| M-INF | 使用无效条件推理方向 | 只可作为未确认候选；由 P03 进行最小探查 |
| M-READ | 证据不足，可能是阅读/注意力滑失 | 低信心、极短作答或无关选项不足以诊断概念错误 |

## 审阅说明

- 所有“错因”在产品中都只能显示为**候选 / 未确认**，而不是对学习者的事实判断。
- D01/D02 只用于观察和路由；P01–P03 用于最小探查；T01–T03 是教学资产；V01/V02 是无提示、未见过的独立迁移；R01/R02 是在迁移后 +3 天的延迟复测。
- V01/V02 的正确答案只有在独立、无提示、未见过的条件同时满足时，才可触发有限的学习状态更新。教学后的正确作答不能当作独立证据。
- D02、V02、R02 明确使用“本题设定的封闭逻辑系统 / 不考虑其他因素”，以避免把现实世界中的例外误判成逆否推理。

## D01 · 入口诊断：只有，从结果回推必要条件

**题干**：园区规定：只有完成门禁登记，才能领取工作牌。小周已经领取工作牌。以下哪项一定为真？

| 选项 | 内容 | 审阅中的意图 |
| --- | --- | --- |
| A | 小周已经完成门禁登记。 | **正确** |
| B | 任何完成门禁登记的人都已经领取工作牌。 | 逆命题 |
| C | 小周领取工作牌是因为他认识园区工作人员。 | 无依据前提 |
| D | 小周无需完成门禁登记也能领取工作牌。 | 与规则矛盾 |

- 形式化：`badge_collected → registration_completed；badge_collected；因此 registration_completed`
- 答案证明：必要条件的形式为“领取工作牌→完成登记”；已知前件为真，可肯定后件。
- 目标技能：S1、S2；候选：M-DIR、M-ROLE、M-READ
- 独立组：`entry-direction-01`
- 记录哈希：`1b1fbb521821aa354535eff7fa99784cdb28a8ab3d3521a3069f1e973199d1a2`

## D02 · 路由诊断：只要，用逆否方向推理

**题干**：在本题设定的逻辑系统中，规则为：若设备完成校验，指示灯必亮（不考虑故障等其他因素）。现知某设备的指示灯没有亮。以下哪项可以必然推出？

| 选项 | 内容 | 审阅中的意图 |
| --- | --- | --- |
| A | 该设备没有完成校验。 | **正确** |
| B | 该设备完成校验后也不一定会亮。 | 与规则矛盾 |
| C | 该设备之前一定亮过。 | 无依据前提 |
| D | 该设备不需要校验。 | 无关结论 |

- 形式化：`validated → light_on；not light_on；因此 not validated`
- 答案证明：封闭规则中，否定后件可按逆否推理得出否定前件。
- 目标技能：S3；候选：M-INF、M-READ
- 独立组：`entry-inference-01`
- 记录哈希：`0f9543e4022bee75ce51483ab79bcd99de6b0bc29f882e5c8926238d53aed346`

## P02 · 最小探查：必要不等于充分

**题干**：规则是“领取设备 → 已登记”。下列哪种情况与规则相容，并最能说明“已登记”不是“领取设备”的充分条件？

| 选项 | 内容 | 审阅中的意图 |
| --- | --- | --- |
| A | 某人已登记，但还没有领取设备。 | **正确：兼容反例** |
| B | 某人未登记，却领取了设备。 | 违反规则 |
| C | 某人领取了设备，却未登记。 | 违反规则 |
| D | 某人领取设备时需要先登记。 | 重复必要性，未检验充分性 |

- 形式化：`received → registered；registered ∧ not received` 是对 `registered → received` 的兼容反模型。
- 答案证明：“已登记且未领取”不违反领取→登记，却反驳登记→领取。
- 区分目标：M-ROLE、M-READ；目标技能：S2
- 独立组：`probe-role-01`
- 记录哈希：`a919de5fd8d494c8b42f1a5263596d9cd0b331fccd0367c50a044ec12ce8952b`

## P03 · 最小探查：脱离语境的条件推理

**题干**：已知 P→Q，且 Q 为真。下列哪项能必然推出？

| 选项 | 内容 | 审阅中的意图 |
| --- | --- | --- |
| A | P 为真。 | 肯定后件 |
| B | P 为假。 | 无依据否定 |
| C | 无法仅凭这些信息确定 P 的真假。 | **正确** |
| D | Q 为假。 | 与已知事实矛盾 |

- 形式化：`P → Q；Q；P` 未定。
- 答案证明：Q 为真可能来自 P，也可能来自其他情况；由后件肯定前件无效。
- 区分目标：M-INF、M-READ；目标技能：S3
- 独立组：`probe-inference-01`

## T01 · 教学资产：一条箭头和一个反例

- 策略：`arrow_counterexample`
- 规则：“只有 A，才 B”等价于 B→A；A 不足以推出 B。
- 教学内容：把“只有完成登记，才能领取工作牌”改写为“领取工作牌→完成登记”。再检验反向：完成登记的人可以暂时不领取工作牌，所以不能从登记推出领取。
- 仅在：P01 支持 M-DIR 时选择；P01 不足以区分时不得自动选择。
- 目标：S1 / M-DIR；独立组：`teach-direction-01`
- 记录哈希：`9c25cdd95ef70cf81ce6a0391f79a7a81b4382a550f4e6085d7e15dc4b5d8909`

## T02 · 教学资产：前提不是保证

- 策略：`necessary_sufficient_contrast`
- 规则：B→A 表示 A 是 B 的必要条件；A∧非B 与该规则相容，因此 A 不必充分。
- 教学内容：必要条件像动作发生前必须具备的证件；有证件只说明不缺这个前提，不说明动作已经发生。用“已登记但未领取”检验：登记必要，但不充分。
- 仅在：P02 支持 M-ROLE 时选择；P02 不足以区分时不得自动选择。
- 目标：S2 / M-ROLE；独立组：`teach-role-01`
- 记录哈希：`8c6bc3e79c51ce3100dec5610f0f9653dd74a1de2220b5cc189b7e91241de0c1`

## T03 · 教学资产：条件推理四格

- 策略：`validity_grid`
- 规则：P→Q 允许 P→Q 与 非Q→非P，不允许 Q→P 或 非P→非Q。
- 教学内容：P→Q 中，P 真可推出 Q；Q 真不能推出 P；Q 假可推出 P 假；P 假不能推出 Q 假。先定位已知事实在箭头哪一侧，再决定能否顺着或按逆否走。
- 仅在：P03 支持 M-INF 时选择；P03 不足以区分时不得自动选择。
- 目标：S3 / M-INF；独立组：`teach-inference-01`
- 记录哈希：`e552a5bb444596a9b29d532b378cac41c83f24999449486239cd008ee20ed619`

# Lumi portfolio evidence

This folder turns the product into a reviewable engineering and research case,
not a claims deck. Fill the templates only with artifacts generated by
`python3 evals/run_all.py` or with clearly cited user-study evidence.

- [DEMO_SCRIPT.md](DEMO_SCRIPT.md) is the live Mac demo runbook.
- [CASE_STUDY.md](CASE_STUDY.md) is the AGI/product case-study template.
- [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md) maps every claim to a reproducible proof.

Rules:

1. Never claim population learning gain from expert fixtures or replay.
2. Label deterministic baselines, model-assisted outputs, and human labels.
3. Show uncertainty and failed/pending gates in the demo.
4. Preserve redacted inputs, versions, hashes, and the exact evaluation command.
5. Treat the production Shenlun repository as read-only context, never as a demo dependency.
